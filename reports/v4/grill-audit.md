# Independent Grill Audit — v4

- 审计日期：2026-08-16
- 审计对象：代码、实验协议、机器结果、HTML 研究备忘录与五页 PDF
- 审计结论：**适合作为量化研究工程/模型风险治理作品；不适合作为成功 Alpha 策略案例。**

## 1. 反方结论先行

如果该项目被描述为“通过稳定性加权获得了更好的交易策略”，结论不成立。扩展方案的成本后年化超额为 -17.50%，信息比率为 -1.738，最大回撤为 -62.44%，并且收益与 IR 均落后于最佳预设对照。机器 Gate 正确输出 BLOCK。

如果该项目被描述为“一套能够发现泄漏、冻结选参、执行真实组合约束并拒绝失败信号晋级的研究验证系统”，证据基本充分。其求职价值来自研究过程的可审计性，而不是负收益本身。

## 3. 仍然不能回避的专业缺口

1. **数据层级有限。** 社区 Qlib 示例数据不能替代机构级 point-in-time 行情、成分股主数据和可交易性清洗，无法据此推断真实部署表现。
2. **统计推断尚不完整。** 名义 ICIR 未对序列相关、多重检验和候选搜索偏差作校正。验证期 4.685–4.754 的高 ICIR 在冻结测试降至 1.093，本身就是过拟合或状态变化警报。
3. **风险归因不足。** 行业、规模、风格暴露未显式中性化；尚不能确认回撤来自信号失效、暴露偏离还是 Top50 集中。
4. **组合端诊断不够细。** 全截面 Rank IC 与 Top50 尾部收益之间缺少分位数组合、top-k 敏感性和持有期衰减曲线。
5. **没有生产证明。** Gate 仅表示是否进入更高保真研究阶段；没有实时数据、订单生命周期、容量、冲击成本或监控系统。

这些缺口不会否定作品集价值，但决定了项目只能主张“研究工程成熟度”，不能主张“具备可交易 Alpha”。

## 5. 最终判定

**作品集展示：PASS（有条件）。** 条件是标题、简历和面试叙述始终将其定位为“量化研究验证与模型风险治理系统”，并主动说明扩展信号被 Gate 阻断。

**策略有效性：BLOCK。** 当前证据不支持任何收益改善或实盘可用性表述。

**下一项最有价值的增强：** 先完成分位数/Top-k 单调性、行业与规模中性化、block bootstrap 三项 P1 检验，再决定是否值得更换数据继续研究；在此之前增加更多页面或动画不会显著提高专业认可度。
